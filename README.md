# STEL Field

Clients, quotes, jobs, tank mixes and spray records on one phone, with or without internet. An installable web app with no server and no login. Everything typed stays on the phone.

It never suggests an application rate. Every rate is typed off the current product label, and the app only does the maths.

## Data and credits

- Products: APVMA PubCRIS open dataset, CC BY 3.0 AU. Names, makers and actives only.
- Map imagery and lot lookups: State of Queensland.
- Forecasts: MET Norway, CC BY 4.0.
